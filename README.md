# MAGAZINE Y

사용자 흐름과 디지털 경험을 설계하는 UI/UX · 웹디자이너 김예지의 포트폴리오 웹사이트입니다.

## 프로젝트 소개

MAGAZINE Y는 매거진 콘셉트를 기반으로 제작한 포트폴리오 웹사이트입니다.

사용자의 시선 흐름과 정보 구조를 고려하여 앱, 웹사이트, 이커머스 프로젝트를 아카이브 형식으로 구성했습니다.

## 사용 기술

* HTML5
* CSS3
* JavaScript
* Figma
* GitHub Pages

## 주요 기능

* 반응형 웹 레이아웃
* 프로젝트 아카이브 구성
* 스크롤 기반 인터랙션
* Intersection Observer를 활용한 Fade-in 애니메이션
* Contact 모달 팝업
* 프로젝트 상세 페이지 및 외부 링크 연결
